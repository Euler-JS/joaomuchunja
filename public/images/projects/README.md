# Imagens dos Projetos

## 📁 Como adicionar imagens reais

1. **Prepare suas imagens:**
   - Formato recomendado: PNG ou JPG
   - Dimensão recomendada: 1200x630px (proporção 16:9)
   - Tamanho: < 500KB (otimize com TinyPNG ou similar)

2. **Nomeie os arquivos:**
   - Use o nome do projeto em minúsculas
   - Exemplo: `passebem.png`, `chatmaza.png`, `fams.png`

3. **Adicione nesta pasta:**
   - Substitua os arquivos placeholder pelos reais
   - Mantenha o mesmo nome do arquivo

## 💡 Dicas para screenshots:

### Para Apps Mobile:
- Use ferramentas como [Mockuphone](https://mockuphone.com/) para criar mockups
- Capture screenshots em dispositivo real ou emulador
- Combine múltiplas telas em uma única imagem

### Para Web Apps:
- Use [Screely](https://screely.com/) para adicionar molduras bonitas
- Capture em tela desktop (1920x1080)
- Mostre a página principal ou dashboard

### Para APIs/Backend:
- Mostre dashboard administrativo
- Capture documentação da API (Swagger/Postman)
- Use diagramas de arquitetura

## 🎨 Ferramentas úteis:

- **Otimização:** [TinyPNG](https://tinypng.com/)
- **Design:** [Canva](https://canva.com/)
- **Mockups:** [Mockuphone](https://mockuphone.com/)
- **Screenshots:** [Screely](https://screely.com/)
- **Edição:** [Photopea](https://photopea.com/) (Photoshop online grátis)
